# MED Departaments (версия для GitHub Pages)

Сайт целиком состоит из статичных файлов: сервер не нужен.
Ключи в коде не хранятся. В файле vault.json лежат только зашифрованные блоки.

## Как выложить
1. Создайте на GitHub публичный репозиторий.
2. Загрузите в него все файлы и папку fonts из этого архива.
3. Settings, Pages: Source = Deploy from a branch, Branch = main, папка = / (root), Save.
4. Через 1-2 минуты сайт откроется по адресу https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/

## Как подключить Discord
1. Войдите как Главный врач, вкладка «Настройка».
2. Вставьте ссылки вебхуков отделов, нажмите «Создать vault.json».
3. Загрузите скачанный vault.json в репозиторий вместо старого. Через 1-2 минуты всё заработает.

## Файлы
- index.html: сайт
- portal.json: отделы, должности, формы архивов
- vault.json: зашифрованные ключи и вебхуки
- fonts/: шрифты
